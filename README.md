# Homebrew tap

This is my Homebrew tap. It holds the formulae for my own tools.

## Install

```sh
brew install elmarbeckmann/tap/wakemeupbt
brew services start wakemeupbt

brew install elmarbeckmann/tap/hubdeck
brew services start hubdeck
```

## Formulae

| Formula | Description |
| --- | --- |
| [wakemeupbt](https://github.com/elmarbeckmann/WakeMeUpBT) | Turn Bluetooth off while a Mac sleeps to stop DarkWake battery drain |
| [hubdeck](https://github.com/elmarbeckmann/hubdeck) | Control Philips Hue, IKEA DIRIGERA and tado from an Elgato Stream Deck |
